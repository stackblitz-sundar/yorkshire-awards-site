# Yorkshire Community & Cultural Excellence Awards 2027

A responsive single-page static website built with HTML5, Bootstrap 5.3, CSS and JavaScript.

## Deploy to GitHub Pages
1. Create a GitHub repository (for example `yorkshire-awards`).
2. Upload `index.html` and the `assets` folder to the repository root.
3. Open Settings → Pages → Deploy from a branch → main / root → Save.
4. Visit the published GitHub Pages URL. Add a custom domain in Pages settings when ready, then configure DNS with your domain provider and enable HTTPS.

## Before going live
- Confirm the award name, any trademark issues and the organiser's legal identity.
- Replace placeholder nomination, contact and announcement notices with verified details.
- Publish complete nomination terms, judging and conflicts policy, and a legally reviewed privacy notice before collecting personal data.
- Add an actual nomination form only when it is ready and its data protection arrangements have been tested.
- Confirm the venue, event date and ticketing terms before advertising tickets.

No nomination form or collection endpoint is enabled in this version. No programme or unconfirmed dates are shown.

## Files
- `index.html` — all sections and content
- `assets/style.css` — visual design and responsive styles
- `assets/script.js` — award category cards and navigation behaviour

External dependencies: Bootstrap and Google Fonts (internet connection required).
